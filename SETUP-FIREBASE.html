Setup Sinkron Firebase

Izud Finance Hub v1.11 · login sekali per perangkat, setelah itu sinkron jalan sendiri tanpa login ulang · ±15 menit

Laptop / HPdata tersimpan di perangkat (catat langsung, tanpa jeda)
⇄
Firebase Firestoredatabase cloud gratis, sinkron ±0,1 detik
⇄
Perangkat lainperubahan muncul sendiri saat app terbuka
Yang kamu butuhkan Akun Google (untuk membuka Firebase console), laptop, HP, file app terbaru dari folder hub/, dan sebuah password baru khusus untuk Finance Hub (minimal 8 karakter, jangan sama dengan password Google).

1Buat proyek Firebase

  1. Buka console.firebase.google.com, login dengan akun Google-mu.
  2. Klik Create a project (Buat proyek). Nama: finance-hub → Continue.
  3. Kalau ditawari Gemini / Google Analytics: matikan (tidak dibutuhkan) → Create project → tunggu selesai → Continue.

2Daftarkan app web & salin konfigurasinya

  1. Di halaman Project Overview, klik ikon </> (Web).
  2. App nickname: Finance Hub. Jangan centang Firebase Hosting → Register app.
  3. Muncul kode berisi blok seperti ini — salin seluruh blok firebaseConfig ke Notes:
const firebaseConfig = {
  apiKey: "AIza…",
  authDomain: "finance-hub-xxxx.firebaseapp.com",
  projectId: "finance-hub-xxxx",
  storageBucket: "finance-hub-xxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abc123"
};
Blok ini bukan rahasia (hanya alamat proyekmu) — yang melindungi data adalah akun + Rules di langkah 5 & 8. Tetap jangan disebar sembarangan. Bisa dibuka lagi kapan saja: ⚙︎ Project settings → General → Your apps.

3Aktifkan login email + password

  1. Menu kiri Build → Authentication → Get started.
  2. Tab Sign-in method → pilih Email/Password → nyalakan saklar pertama (Email/Password). Saklar kedua "Email link (passwordless)" biarkan mati → Save.

4Buat akunmu (satu akun untuk laptop & HP)

  1. Masih di Authentication, tab Users → Add user.
  2. Isi email-mu dan password baru khusus Finance Hub → Add user.
  3. Simpan password ini di password manager. Inilah yang diketik sekali di tiap perangkat.

5Kunci pendaftaran akun baru

  1. Authentication → tab Settings → User actions.
  2. Matikan "Enable create (sign-up)" → Save. Dengan begitu tidak ada orang lain yang bisa membuat akun di proyekmu.
  3. Masih di Settings → Authorized domains → Add domain → izzuddd.github.io → Add.

6Buat database Firestore

  1. Menu kiri Build → Firestore Database → Create database.
  2. Kalau ditanya edisi: pilih Standard.
  3. Location: pilih yang di Eropa, mis. eur3 (europe) atau europe-west3 (Frankfurt) — paling dekat ke Istanbul. Lokasi tidak bisa diubah setelah dibuat.
  4. Pilih Start in production mode → Create.

7Pastikan database sudah jadi

Tunggu sampai halaman Firestore menampilkan tab Data, Rules, Indexes. Tidak perlu membuat collection apa pun — app membuatnya sendiri.

8Pasang Rules (hanya kamu yang bisa baca/tulis)

  1. Firestore → tab Rules → hapus semua isinya → tempel:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/rows/{row} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
  1. Klik Publish. Selesai di sisi Firebase.

9Update app di GitHub (v1.11.0)

  1. Upload / timpa ke repo: js/fb.js (file baru), js/sync.js, js/pages/settings.js, sw.js, SETUP-FIREBASE.pdf.
  2. Edit js/config.js langsung di GitHub → APP_VERSION: '1.11.0' → Commit.
  3. Tunggu ±1 menit, buka app, reload 2× → ⚙︎ Pengaturan → bagian Tentang harus v1.11.0.
Jangan upload folder migration/ atau file .json cadangan — itu data keuanganmu.

10Hubungkan laptop (perangkat pertama)

  1. Pastikan data di laptop adalah yang paling baru. Kalau ragu: ⚙︎ → ⬆ Impor JSON → pilih migration/last-updated/finance-hub-backup-2026-10-04.json.
  2. ⚙︎ → kartu Sinkron Firebase (login sekali):
    • tempel blok firebaseConfig dari langkah 2
    • email & password dari langkah 4 → Masuk & sinkron.
  3. Karena cloud masih kosong, laptop mengunggah semua data (±2.250 baris, beberapa detik). Status menjadi Tersinkron (Firebase).

11Hubungkan HP

  1. Kirim blok firebaseConfig ke HP (AirDrop / Notes).
  2. Buka app dari layar utama (bukan Safari biasa — penyimpanannya terpisah) → ⚙︎ → tempel config + email + password → Masuk & sinkron.
  3. HP menarik semua data dari cloud. Data yang hanya ada di HP ikut dikirim ke cloud — tidak ada yang hilang.

12Tes 1 menit

  1. Catat transaksi uji di HP (mis. "tes 1000").
  2. Lihat laptop (app terbuka): transaksi muncul sendiri dalam ±1–2 detik, tanpa reload.
  3. Hapus transaksi uji dari salah satu perangkat — ikut terhapus di perangkat lain.
Selesai. Mulai sekarang buka app dan langsung pakai — tidak ada login lagi, tidak ada titik kuning tiap jam.

Kalau ada masalah

Pesan di appPenyebab & solusi
Email atau password salahCek akun di Authentication → Users (langkah 4). Bisa reset password di sana (⋮ → Reset password).
Konfigurasi Firebase tidak lengkapTempel seluruh blok firebaseConfig (langkah 2), termasuk apiKey dan projectId.
Akses Firestore ditolakRules belum di-Publish atau isinya salah (langkah 8), atau login dengan akun berbeda di perangkat lain.
Database Firestore belum dibuatKerjakan langkah 6.
Firebase tidak bisa dihubungiKoneksi putus — app mencoba lagi otomatis; data tetap aman di perangkat.
Login Firebase sekali di PengaturanPerangkat ini belum/tidak lagi login → ⚙︎ → masukkan email & password.
Keamanan singkat Data hanya bisa dibaca/ditulis oleh akunmu (Rules langkah 8). Pendaftaran akun baru dimatikan (langkah 5). Password tidak disimpan oleh app — yang tersimpan hanya sesi login Firebase di perangkat itu. Kalau HP hilang: Firebase console → Authentication → Users → ganti password (sesi lama ikut tidak berlaku saat token diperbarui).
